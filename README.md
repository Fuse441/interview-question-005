# interview-question-005

A queue management system built with ASP.NET Core Web API and Angular.

This project provides a simple ticket queue workflow where users can take queue numbers, view the current queue, and reset the queue state through a clean web interface and RESTful API.

The queue system automatically generates ticket numbers sequentially from `A0` to `Z9`.

Example:

```text
A0 → A1 → A2 ... A9 → B0
```
